## Ce que j'ai livré (branche `node-d-xr-stereo`, commits jusqu'à `bejf97bu8`… voir git log)

### 1. Correction de la luminosité
- Shader NV12 : `_Gain` / `_Gamma` / `_Lift` (exposition / gamma / niveau
  de noir).
- **Auto-grade au 1er lancement** si la source est sombre et que tu n'as
  jamais réglé toi-même → il remonte tout seul.
- Panneau **« Picture ▼ »** : 3 réglettes + Auto / Reset / Save.
- Ligne d'état **« source luma a/b/c — live image / LIKELY BLACK »** : dit
  sans ambiguïté si la Switch dort / pas de signal.

### 2. Outil de calibration stéréo (ton objectif principal)
Panneau **« Stereo ▼ »** en bas à gauche :
- **Stereo ON/off** · **View** (Full / Œil G / Œil D / SBS ajusté /
  Anaglyphe / Fantôme superposé).
- **Detect geometry** + **Apply ▸ sliders** : scanne l'image, trouve la
  couture SBS et la boîte de contenu de chaque moitié, pré-règle les
  réglettes.
- **Test patt** : mire SBS synthétique (cercles concentriques + croix +
  grille) pour régler split / convergence / offsets **sans même la Switch**.
- **9 réglettes** : split X source, échelle, offset X/Y par œil,
  convergence, distortion k1 / k2.
- **Grid** : lignes-guides (couture magenta, centres d'œil verts).
- Tout est persisté (`nuvc.st.*`), partagé avec la future version XR.

⚠️ **Un panneau 2D ne peut que *prévisualiser* la stéréo** — la vraie
vision par œil (chaque œil son image) demande un build XR. Le shader
`Hdmr/NuvcStereoXR` (par-œil, stereo-instanced) est écrit et prêt. Plan
complet : `research/nuvc-xr-real-stereo-plan.md`.

## À faire quand le casque est rechargé (dans l'ordre)

1. Recharge le Quest **branché** (le stream tire ~1 %/min).
2. `adb connect …:5555`, `pm disable-user --user 0 com.meta.quest_hard_link`,
   installe `Build/HDMR-nuvc.apk`, lance nuvc.
3. Ouvre **Stereo ▼** → **Test patt** d'abord : vérifie que split /
   convergence / distortion se règlent proprement sur la mire.
4. Test patt OFF, Switch en mode VR : **Detect geometry** → **Apply**, puis
   **View = Ghost overlay** pour la convergence, **View = Œil G/D** pour
   régler k1/k2 (lignes droites = droites).
5. Décide : le résultat 2D head-locked suffit, ou on lance le build XR
   par-œil (`research/nuvc-xr-real-stereo-plan.md`).
